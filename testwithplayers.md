# testwithplayers — проверки с настоящими игровыми клиентами

## Граница этого файла

Здесь только клиентские и end-to-end многопользовательские проверки, которые
текущий headless-стенд не доказывает. Они **не пройдены** наличием этого списка.
Серверный урон, крит, sweep, броня, эффекты, инвентарь, AI, мир, чанки, редстоун,
контейнеры и сохранение должны проверяться автоматикой, даже когда для теста
создаётся объект `Player`. Такой объект не требует человека и не переносит
проверку сюда. Полнота списка относительно всех будущих механик не заявляется.

## Общий протокол

- [ ] Два чистых клиента Java **26.3**, без модов; записать build клиента,
  SHA Steel, seed, gamerules, dimension, difficulty, настройки view/simulation.
- [ ] Тот же сценарий повторить на официальном vanilla **26.3**, с тем же миром
  / исходной структурой и настройками. Ожидаемое поведение — результат vanilla,
  не «так выглядит нормально». Не исправлять golden ради зелёного отчёта.
- [ ] Для каждого пункта сохранить шаги, серверные логи, видео обоих клиентов,
  результат до/после reconnect и PASS/FAIL/BLOCKED. Чекбокс без артефакта не PASS.
- [ ] Сетевая матрица: обычная сеть; задержка 100 и 250 мс; потеря пакетов 1%;
  ограничение пропускной способности. Проверить отсутствие дюпа/потерь/
  необратимого рассогласования. Эти значения — стресс-профили, не нормы vanilla.

## Вход, протокол и отображение

- [ ] Online-mode вход с действительной сессией, отказ недействительной сессии,
  повторный вход; корректные тексты disconnect и отсутствие зависшей сессии.
- [ ] Configuration → Play, registry/tags/recipes, code of conduct и возврат
  в configuration: клиент не падает и не остаётся на loading screen.
- [ ] Resource pack: принять/отклонить/неудачная загрузка/замена; сверить диалоги
  и действия сервера с vanilla, без обхода проверки hash/URL.
- [ ] Чат и подписи сообщений, chat settings, whispers/team chat, Unicode,
  suggestions/таб-комплит, кликабельный текст, книги/таблички/диалоги.
- [ ] Tab-list, skin/cape/model layers, scoreboard/team/name tags, bossbars,
  titles/actionbar/advancements/toasts, звуки и частицы видны нужным клиентам.

## Передвижение, мир и tracking

- [ ] Ходьба/бег/прыжок/приседание/ползание/плавание/elytra/riptide: камера,
  поза, hitbox и отображение второго игрока совпадают с vanilla.
- [ ] Телепорт и подтверждение, portal/nether/end/возврат, respawn и credits:
  нет rubber-banding, старых сущностей или навсегда открытого loading screen.
- [ ] Встречное движение двух клиентов через границы чанков/измерений;
  корректные spawn/despawn, metadata, equipment, passenger/leash и interpolation.
- [ ] Лодки/плоты/chest boats/minecarts/животные: mount/dismount, смена водителя,
  экран управления, камера пассажира, отображение движения для наблюдателя.
- [ ] Разрушение/установка на границе reach, с разных граней и при высокой
  задержке: acknowledgement, cracks, prediction и rollback, без ghost blocks.
- [ ] Client lighting/biome colors/heightmap, chunk seams и изменение света
  при перемещении источника/перезагрузке чанка; сравнить скриншоты с vanilla.

## Бой: клиентский end-to-end слой

Серверные формулы и условия тестируются без людей; здесь только доставка
действий, отображение и рассинхронизация.

- [ ] PvP два клиента: одиночный удар, удержание атаки, частые клики, смена оружия;
  cooldown indicator соответствует реально принятому удару после задержки.
- [ ] Крит/обычный/sprint/sweep: оба клиента согласны об анимации, звуке,
  частицах, damage flash и потерянных сердцах; блокированный удар не показывает
  успешный крит. Sweep не превращает axe/кулак в sword на клиенте.
- [ ] Щит: raise/lower, правая/левая рука, оглушение топором, поломка; нет
  невидимого блокирования после отпускания клавиши или смены слота.
- [ ] Knockback/отбрасывание sprint, сопротивление и удар у края: движение
  жертвы и вид наблюдателя сходятся, нет повторного импульса после коррекции.
- [ ] Bow/crossbow/trident/spear/mace: charge/use/release, прицеливание,
  анимация снаряда, попадание и возврат видны обоим клиентам без дубликатов.
- [ ] Fire aspect/огонь/poison/wither/thorns/totem/absorption: HUD, частицы,
  анимация смерти/спасения, combat/death messages; зритель видит тот же исход.
- [ ] Смерть PvP, respawn, spectator-target, keepInventory on/off, disconnect
  во время боя: нет второго трупа, повторного лута и пропавшего управления.
- [ ] Команды/team friendly-fire/PvP=false: запрещённый сервером удар корректно
  откатывается, не оставляет повреждённую броню/оружие или ложное здоровье UI.

## Экраны, инвентарь и совместные взаимодействия

- [ ] Все menu types, creative inventory и survival crafting: drag, shift-click,
  number keys, double-click, drop, offhand swap; cursor после закрытия/смерти.
- [ ] Два клиента одновременно используют один контейнер, забирают последний
  предмет, закрывают окно, уходят за reach, ломают/перемещают контейнер:
  нет дюпа, ghost slots или потерянного cursor stack.
- [ ] Merchant/enchant/anvil/smithing/grindstone/loom/stonecutter/cartography:
  preview, цена, подсказки, recipe book и фактически полученный результат
  синхронны; устаревший preview не позволяет забрать результат бесплатно.
- [ ] Bundle, books, maps, banners, dyed armor, components/tooltips, durability,
  cooldown overlays, equip/use animations отображаются как на vanilla.
- [ ] Sign front/back, lectern page, decorated pot, bookshelf, item frame,
  armor stand, jukebox: второй клиент сразу получает изменение.

## Интерфейсы существ и совместный gameplay

- [ ] Bossbar dragon/wither/raid: имя/цвет/прогресс/появление/удаление и дистанция
  отображения на обоих клиентах; reconnect не дублирует bossbar.
- [ ] Trading, tame/feed/breed/mount/inventory pets: правильный экран и
  анимация, смена владельца/поводка видна наблюдателю без stale metadata.
- [ ] Bed/sleep/wake/death while sleeping,многопользовательский sleep threshold:
  синхронизация времени, экрана сна и выхода из кровати.
- [ ] Spectator/creative/adventure/survival transitions: abilities, flight,
  camera, invisible/spectator entities и доступность меню обновляются сразу.

## Надёжность сессии

- [ ] Reconnect при открытом меню/использовании предмета/езде/portal transition;
  состояние восстанавливается, управление и курсор не зависают.
- [ ] Серверный restart при двух клиентах: корректный disconnect, восстановление
  позиций/инвентарей/измерений после входа, отсутствие дубликатов сущностей.
- [ ] Полный повтор отмеченных FAIL после исправления на том же наборе клиентов
  и сетевых профилей; сохранение ссылки на первоначальный failure.
